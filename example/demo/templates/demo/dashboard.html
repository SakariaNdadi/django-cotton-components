  • Articles table — filter by Status / Featured, search, sort, tick rows for bulk actions (with “select every matching row”), row actions as a page, an inline toggle, and a modal quick-edit. Seed --big 60000 to see it switch to streamed server-side scrolling (no COUNT, keyset cursor).
