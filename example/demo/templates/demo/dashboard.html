Try every feature
  • Articles table — filter by Status / Featured, search, sort, tick rows for bulk actions (with “select every matching row”), row actions as a page, an inline toggle, and a modal quick-edit. Seed --big 60000 to see it switch to streamed server-side scrolling (no COUNT, keyset cursor).
  • Schema form — sections, searchable selects, a field that appears only when Status = Live, and a Pillow-validated image upload. Works with JavaScript disabled.
  • Publish wizard — steps advance over htmx (no full-page reload); per-step Django validation.
  • Component gallery — every primitive: buttons, badges, icons, modal, menu, and all form controls.
  • Panel dashboard — stat / chart / table widgets, a custom Reports page, and Article / Author resources with list · create · edit · view · delete + a declared infolist.
  • Comments (no-code) — a full resource defined entirely by a stored DashboardSpec JSON row, no Python subclass.
